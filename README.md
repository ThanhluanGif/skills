## 📌 GIỚI THIỆU LUNAR SKILLS

**Lunar Proactive AI Skill System (`lunar-skills`)** là bộ hạ tầng chuyên dụng giúp tối ưu hóa quy trình tương tác giữa con người và các AI Agent (Gemini, Antigravity, AGY CLI) trong hệ sinh thái **Lunar**. 

---

## 💻 HƯỚNG DẪN CÀI ĐẶT & SỬ DỤNG

### 1. Cài đặt 1-Click vào bất kỳ dự án nào

```bash
# Cài đặt tự động Skills vào dự án của bạn
npm i lunar-skills

# Hoặc kích hoạt nhanh bằng npx:
npx lunar-skills setup
```

### 2. Khởi chạy Visual Dashboard

```bash
# Khởi chạy Server HTTP (Port 3000)
npx lunar-skills

# Mở trình duyệt xem Dashboard trực quan:
http://localhost:3000
```

### 3. Kiểm thử Tự động 1-Click (Automated Verification)

```bash
# Kiểm tra toàn bộ 5 kịch bản kiểm thử
npx lunar-verify
```
